# dripper

A graffiti marker painter with wet-ink drips, a marker and spray-can brush mode, and grainy overspray mist.

## Features

- **Marker mode** — flat, opaque strokes with circle or chisel nibs, adjustable nib angle
- **Spray mode** — soft round cone with grainy edges, an overspray Mist slider (density) and Spread slider (reach)
- **Dynamic width** — fast strokes taper thin, slow strokes stay full width
- **Wet-ink drips** — strokes deposit ink that pools and drips under gravity, with controls for wetness, frequency, wander, trail width, and size variation
- **Opacity** — strokes composite as one uniform translucent mark, not stacked overlapping dabs
- **Custom backgrounds** — paint over the default paper or an uploaded image
